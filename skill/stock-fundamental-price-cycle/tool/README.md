# Stock Cycle Lab v3.0.0

独立、跨市场的「基本面筛选 + 价格周期」研究工具。自选股、商品股、行业或指数成分只是输入股票池，不是功能边界。当前市场配置覆盖中国A股和美股；其他市场需要新增且测试市场配置。

## 不使用 Codex 的运行方式

把 Stock-Cycle-Lab.html 复制到另一台电脑，用现代桌面浏览器打开即可。文件内含界面、计算核心和合成示例，无需 Python、Node、同花顺、账号或联网。所有导入数据留在本机；页面的内容安全策略禁止网络连接。

1. 先用「加载合成演示 → 运行评估」检查本机浏览器是否可用。演示数字不是推荐门槛或真实行情。
2. 导入自己的标准 JSON 数据包，或选择 CSV 目录中的六个文件。
3. 选择市场参数。A股使用原门槛。美股市值和日均成交额必须独立填写美元值，并确认市值口径。
4. 运行、筛选三层名单，查看逐股证据；导出结果与配置。

更换数据或参数会清空旧结果。取消运行不输出部分结果。大股票池受本机内存影响，可使用命令行或按明确股票池分批；分批结果不能自动标成全市场覆盖。

浏览器需要 File/Blob、Web Worker、Web Crypto、Intl 和 dialog 等现代标准能力。设计面向 Windows/macOS/Linux 的现代桌面浏览器，不承诺所有旧系统/浏览器都能运行。实际验证范围见 VALIDATION.md。

## 命令行（可选）

安装 Node.js 20 或更新版本后，无需 npm install：

~~~text
node cli.js --input my-input.json --config my-config.json --out new-run-directory
node cli.js --input my-csv-directory --config my-config.json --out new-run-directory
node cli.js --demo --out synthetic-demo-run
node --test tests.js
~~~

路径相对于当前目录，可使用绝对路径。输出目录必须尚不存在。浏览器和命令行用同一 engine.js，输出 results.json、results.csv 和运行清单；没有下单功能。

## 数据不是软件的一部分

这个版本是可独立运行的计算/导入工具，**不包含自动下载全部A股或美股实时数据的服务**，也没有伪装成可用的行情API。真实全市场扫描需要你合法取得完整证券主表、行情、财报和交易状态数据。支持导入标准CSV/JSON，数据供应商不被写死，具体格式见 DATA_FORMAT.md。源格式不同需先按合同映射。

不能因为输入文件写了“全市场”就宣称全量：预期数量、实际证券、成分时点、来源、失败分区和覆盖证明都要一致。不能用实时总市值填充历史流通市值，也不能用SEC年报里历史public float冒充当日值。

## 美股独立美元参数

按用户要求，美股不换算人民币、不套用A股市值/成交额阈值。默认 capMin、capMax、amountMin 为 null，直到用户设置。界面美股输入单位是“百万美元”，数据文件用“美元”基础单位；A股界面用“亿元”，数据文件用“元”。

默认美股市值口径为 public_float；如只有总市值，可显式选择 total_market_cap 作为另一研究变体，不静默替换。美股没有A股ST/日涨跌停门槛，但仍检查交易暂停、上市时间和流动性。美股适配未经收益回测验证。

## Skill 只是可选入口

同包 skill/stock-fundamental-price-cycle 可以复制到支持该格式的助手技能目录。新的调用名是 $stock-fundamental-price-cycle。它读取同一工具合同、准备数据、调用引擎并解释结果；工具本身不需要助手。原A股名称在当前电脑保留兼容入口，不作为范围限制。

## 可复现与局限

模型版本、输入、配置和引擎有SHA256指纹；参数变更记录在overrides。所有日线事件按历史顺序计算，不由模型自由填写true/false。详见 MODEL.md。

v3是完整原始数据计算实现，进一步量化了v2里尚需人工解释的筑底、周线支撑与平台ATR条件；因此不承诺复现旧版名单。此工具没有回测绩效、交易成本/成交模拟或盈利证明。它辅助研究，不是个性化投资建议。
