# 跨市场基本面＋价格周期

调用可移植的Stock Cycle Lab，而不是依赖当前对话记忆生成筛选结论。能力范围为有充分数据的CN/US普通股或ADR；股票池是输入，不把自选股、某行业或某次测试数量写成能力上限。

## 必读与执行

1. 读[tool/MODEL.md](tool/MODEL.md)和[tool/DATA_FORMAT.md](tool/DATA_FORMAT.md)，了解模型、数据口径、市场差异及v3迁移。
2. 使用[tool/engine.js](tool/engine.js)中的DEFAULTS为参数基线。用户覆盖记入overrides；没有用户授权不优化阈值、不放宽门槛求更多候选。
3. 确定截至时点、股票池边界、市场、币种和代表性基准。完整市场任务先获取当期证券主表；数据缺口保留分母和失败分区，不冒称全量。
4. 获取或接收财报、证券状态、日线、基准和真实交易日历；按数据合同转换为JSON/CSV。使用可用且获授权的数据源，不依赖特定电脑/同花顺路径，不因工具可用自行访问交易账户。实际财报公告时间和复权口径必须可核验。
5. 默认美股市值/成交额为独立美元参数，未填时可以输出形态和未知项，但不得自行换汇/臆定门槛。先读取用户给定配置；如仍缺少，只问所需美元区间、成交额及市值口径。美股适配是研究变体，不宣称已验证收益。
6. 运行独立工具，从原始数据计算，不接受助手凭印象写出的形态布尔值：

~~~text
node SKILL_DIR/tool/cli.js --input INPUT.json --config CONFIG.json --out NEW_OUTPUT_DIR
node SKILL_DIR/tool/cli.js --input CSV_DIRECTORY --config CONFIG.json --out NEW_OUTPUT_DIR
~~~

没有自定义配置可省略--config，但美股空门槛仍未知。没有Node时，用户可直接用现代浏览器打开[tool/Stock-Cycle-Lab.html](tool/Stock-Cycle-Lab.html)，导入同样数据离线运行，无需Codex、同花顺或Python。工具不内置自动全市场行情服务；无数据源时解释缺口并请求导出/来源，不能伪造已扫描结果。

## 输出

先报告版本、数据时间、配置/输入指纹、股票池覆盖率、各市场交易日、基准及币种。按同一结果集分三层：

- 基本面通过；
- 基本面及可交易性通过；
- 完整策略资格（可能为零）。

区分当日新事件、活动周期、市场环境、策略资格与模型动作。保留逐股阻断项、公告组件、数值证据和前向事件账本。不把通过基本面写成当前可以买；超涨和跌破阶段独立呈现。名字从数据源提取，代码为主键。

解释方法时可读[tool/README.md](tool/README.md)；测试与实际验证边界见[tool/VALIDATION.md](tool/VALIDATION.md)。收益回测/成交执行不是已实现功能，用户要求时另立明确任务，不用合成演示或单次筛选证明有效。

## 不漂移也不固化错误边界

参数、计算方法和数据合同版本化；股票池、数据来源、日期及市场实例每次重取。自选股和商品股均是测试案例，不作默认范围。模型变更须升级版本并运行tool/tests.js；仅输入变化不修改技能。旧A股名称是兼容入口，v2历史名单不是v3验证结果。
